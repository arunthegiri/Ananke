hand; `SkillRegistry` verifies every file's sha256 against `manifest.json` at startup and the backend

Each pack directory carries the upstream licence files. Files are copied unmodified; only
documentation (`.md`/`.txt`) inside the listed skill directories is taken — upstream scripts, IaC
templates, hooks and telemetry are excluded, and nothing here is ever executed.
All five licences permit redistribution, so every pack is `distribution: "vendored"`. A future pack
whose licence does not would be `"fetch"`: checksummed in the manifest, downloaded at install time with
`node scripts/skills/vendor-skills.mjs install <ananke.skills.fetch-dir>`.
